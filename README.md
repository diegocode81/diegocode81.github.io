# Diego Mauricio Molina Mesias - Professional Portfolio

Modern, responsive, recruiter-friendly portfolio for Diego Mauricio Molina Mesias, focused on QA Architecture, Senior Automation Engineering, API testing, mobile automation, CI/CD quality gates, and AI-assisted Quality Engineering.

Final GitHub Pages URL:

```text
https://diegocode81.github.io
```

## Technologies Used

- React
- Vite
- Tailwind CSS
- JavaScript
- GitHub Pages
- gh-pages

## Local Setup

Install dependencies:

```bash
npm install
```

Run the local development server:

```bash
npm run dev
```

## Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Deploy

Deploy the `dist` folder to GitHub Pages:

```bash
npm run deploy
```

## GitHub Pages Configuration

This repository is a GitHub user page repository named `diegocode81.github.io`.

Vite is configured with:

```js
base: "/"
```

Do not use:

```js
base: "/portfolio/"
base: "/diegocode81.github.io/"
```
